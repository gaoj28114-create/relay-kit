# 状态文件格式

> 这一页是给**想手工改、或想自己写工具读写**的人看的。日常用不着。

## 状态目录在哪

按顺序解析，先命中先用：

| 顺序 | 来源 | 说明 |
|---|---|---|
| 1 | 环境变量 `RELAY_HOME` | 临时改位置用，优先级最高 |
| 2 | 本技能 `config.json` 里的 `state_root` | 想固定位置就写这里 |
| 3 | `~/.relay` | **默认**。任何机器都算得出来 |

Windows 下 `~` = `C:\Users\<用户名>`。

**这个目录不在技能里**，所以在技能根建 junction / 软链、或把技能打包发给别人，都不会带走你的数据。

## 目录结构

```
~/.relay/
├── tasks/                    # 每个任务一张卡
│   ├── 20261020-143022.json
│   └── 20261020-151108.json
├── 用户画像.md                # 人读的偏好清单
└── cap_index.json            # 能力索引（预生成，省上下文）
```

## 任务卡格式

```json
{
  "id": "20261020-143022",
  "title": "给爬虫加断点续传",
  "goal": "让抓取中断后能从上次的位置继续",
  "deliverable": "改好的 fetch.py + 一份说明",
  "domain": "python 爬虫",
  "criteria": "杀掉进程重启，能从断点继续，且不重复抓",
  "status": "active",
  "style": "严谨档",
  "decisions": [
    { "at": "2026-10-20 14:31", "text": "状态存 sqlite，不用 jsonl" }
  ],
  "todos": [
    { "at": "2026-10-20 14:32", "text": "加 checkpoint 表" }
  ],
  "artifacts": [
    { "at": "2026-10-20 15:10", "text": "E:\\crawl\\fetch.py（v2）" }
  ],
  "blockers": [
    { "at": "2026-10-20 15:12", "text": "目标站限速，压测拿不到稳定数据" }
  ],
  "log": [
    { "at": "2026-10-20 14:30", "text": "原始需求：给爬虫加断点续传" }
  ],
  "created_at": "2026-10-20 14:30",
  "updated_at": "2026-10-20 15:12"
}
```

### 字段含义

| 字段 | 说明 |
|---|---|
| `id` | 建卡时间戳，目录内唯一。文件名就是它 |
| `status` | `active`（进行中）/ `paused`（暂停）/ `done`（收尾） |
| `style` | 风格档：`严谨档` / `自适应档` / `参照档` |
| `decisions` | **已定的事**。接手的 AI 靠它避免重问——**最重要的一栏** |
| `todos` | 待办 |
| `artifacts` | 已产出的东西（写路径） |
| `blockers` | 卡在哪 |
| `log` | 过程留痕。建卡时会自动记一条 `原始需求：…` |

### 为什么 `decisions` 最关键

接手的 AI 只能读这个文件。**你口头说过、但没写进来的结论，它一律不知道**，于是会重新问一遍。

判据很简单：**"这件事如果换个 AI，需不需要重新问？"** 需要 → 就该写进 `decisions`。

## 用户画像格式

纯 markdown，一行一条，`- ` 开头：

```markdown
# 用户画像

> 由「接力包」维护。只存**稳定、可跨任务复用**的偏好，不存一次性指令。
> 本文件仅存在于本地，不上传任何服务。

最近更新：2026-10-20 15:20

- 回复始终用简体中文
- 代码注释用中文
- 不喜欢紫色配色
```

读的时候只看 `- ` 开头的行，其他随便写。

**边界**：不记录一次性指令、临时上下文、未确认的推测；**凭据密钥一律不入画像**。

## 能力索引格式

`cap_index.json` 是**预生成的**，目的是让 AI 一次读取就知道本机有什么能力，不用逐个打开 SKILL.md：

```json
{
  "generated_at": "2026-10-20 15:20",
  "roots": ["C:\\Users\\me\\.agents\\skills"],
  "counts": { "skill": 51, "script": 8 },
  "items": [
    {
      "kind": "skill",
      "name": "任务接力",
      "desc": "一句话描述（截断到 220 字）",
      "path": "C:\\Users\\me\\.agents\\skills\\任务接力",
      "root": "C:\\Users\\me\\.agents\\skills"
    }
  ]
}
```

`kind` 取值：`skill` / `script` / `note`。
装了新技能或改了脚本后，跑一次 `cap_index.py build` 重建。

## 手工改的注意事项

- **改完存 UTF-8**，别存成 GBK，否则中文乱码。
- **JSON 别写坏**——`relay.py` 读不出来的卡会被跳过（不会崩，但那张卡就"消失"了）。
- **`id` 别改**，它是文件名和引用键。
- **想批量编辑**，直接写个脚本遍历 `tasks/*.json` 即可，格式就是普通 JSON。
