# 分发说明

> 这一页给**要把接力包发给别人**的人看。

## 一、核心原则：技能与数据分离

| | 在技能目录里 | 在 `~/.relay` 里 |
|---|---|---|
| 代码、文档、默认配置 | ✓ | |
| 你的任务卡 | | ✓ |
| 你的用户画像 | | ✓ |
| 你的能力索引 | | ✓ |

**所以：打包技能目录发出去，不会泄露任何你的个人数据。** 对方拿到的是干净的工具。

## 二、打包

### 要发的

```
接力包/
├── SKILL.md
├── 安装.py
├── 秒上手.md
├── config.json
├── scripts/
│   ├── relay.py
│   └── cap_index.py
└── references/
    ├── 状态文件格式.md
    └── 分发说明.md
```

### 发之前必须清掉的

- `config.local.json`（如果存在——本机覆盖配置）
- `__pycache__/`、`*.pyc`
- 任何你自己调试时留下的临时文件

### 一行打包命令

Windows（PowerShell）：
```powershell
Compress-Archive -Path "接力包" -DestinationPath "接力包.zip" -Force
```

macOS / Linux：
```bash
zip -r 接力包.zip 接力包 -x "*/__pycache__/*" "*.pyc" "config.local.json"
```

### 交付前自查

- [ ] `config.json` 里 `state_root` 是空的（别把你的绝对路径带出去）
- [ ] 没有 `config.local.json`
- [ ] 没有 `__pycache__` / `.pyc`
- [ ] **没有把 `~/.relay` 一起打包**
- [ ] 在另一台机器上试过一次 `python 安装.py --dry-run`

## 三、对方怎么装

一句话告诉对方：

> 解压，进目录，运行 `python 安装.py`，然后**新开一个会话**。

前提只有一个：有 Python 3.7+。

## 四、装到多个客户端

`~/.agents/skills` 是 Agent Skills 生态的跨工具共享目录。装在这里，多数客户端都能看见。

如果对方用的客户端读别的路径，可以装多份：

```bash
python 安装.py --root ~/.claude/skills
python 安装.py --root ~/.cursor/skills
```

先看看对方机器上有哪些技能根：

```bash
python 安装.py --list
```

**更省事的办法**：如果 skills CLI 可用（`npx skills`），用它一次装到所有已存在的客户端：

```bash
npx skills add <你的仓库路径> -g
```

## 五、常见问题

| 问题 | 答 |
|---|---|
| **要联网吗？** | 不用。全程本地文件读写。 |
| **要装依赖吗？** | 不用。Python 标准库。 |
| **会上传数据吗？** | 不会。代码里没有任何网络调用。 |
| **能装到 Windows 和 Mac 吗？** | 都能。路径用 `os.path` / `expanduser` 处理，没有硬编码分隔符。 |
| **对方没装任何技能能用吗？** | 能。接力功能不依赖技能根，只有第 ① 级路由会空。 |
| **注入块会覆盖对方已有的 AGENTS.md 吗？** | 不会。只追加/替换 `<!-- BEGIN relay-kit -->` 到 `<!-- END relay-kit -->` 之间那段。 |
| **对方想卸载干净？** | `python 安装.py --uninstall`，再手动删技能目录和 `~/.relay`。 |

## 六、安全说明（对方问起就答这个）

**代码层面可自查**：

- 两个脚本只 import 标准库：`argparse` / `io` / `json` / `os` / `re` / `shutil` / `sys` / `datetime`
- 没有任何 `socket` / `urllib` / `requests` / `subprocess` 调用
- 写文件只发生在两处：`~/.relay/`（状态）和规则文件里的标记块之间
- 安装脚本复制文件用 `shutil.copytree`，只针对技能自身目录

**自查命令**（对方可以自己验）：

```bash
grep -rnE "import (urllib|requests|socket|http)|subprocess|eval\(|exec\(" 接力包/
```

预期：**没有输出**。

**注入块的影响面**：它只是往 `AGENTS.md` / `CLAUDE.md` 追加一段文字，本机没装这个技能时**会提示用户安装**（提示即止，不会代替用户安装）。不含任何执行权限授予、不改变客户端配置。

**注意**：注入块是**文字指令**，不是系统钩子。它能让 AI 更可能在你说了「继续」时去读状态，但**不保证**——这是本方案已知的局限，别对着它承诺"必定自动"。

## 七、如果想做成公开可安装的

把技能目录推到一个 git 仓库，对方就能：

```bash
npx skills add <owner>/<repo>@接力包 -g
```

注意事项：

- 仓库根目录直接放 `接力包/` 就行，skills CLI 会按目录名识别 skill
- `SKILL.md` 的 frontmatter 必须合法（`name` 要和目录名一致，`description` 含多句中文时**加引号**）
- 首次被别人通过 skills.sh 安装时，平台会做一次自动安全审计
- 建议**钉住 commit**，避免上游后续改动被静默引入
